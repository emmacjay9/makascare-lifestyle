# Makascare Lifestyle V5
Final polish build for the catalogue/enquiry website.

## Included
- Animated premium homepage
- 64-product searchable/filterable catalogue
- Product quick-view and WhatsApp enquiry flow
- Responsive mobile navigation
- Facebook + TikTok + WhatsApp contact paths
- Reviews and customer-experience disclaimer
- Privacy page and terms/product-information page
- SEO/open-graph metadata
- Reduced-motion accessibility support

## Run locally
npm install
npm run dev

## Before launch
1. Replace placeholder domain in `app/layout.tsx` if the final domain is different.
2. Add product prices only when confirmed by Makascare.
3. Review business-specific delivery/returns wording before publishing.
